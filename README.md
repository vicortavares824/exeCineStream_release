# CineStream

Aplicativo de streaming de filmes e séries para Windows.

Este repositório publica apenas os instaladores e as atualizações do app. O código-fonte é privado.

## Download

Baixe a versão mais recente na página de [Releases](../../releases/latest):

| Arquivo | Para que serve |
| --- | --- |
| `CineStream-Setup.exe` | Instalador recomendado. Recebe atualizações automáticas. |
| `CineStream-Portable.exe` | Versão portátil, sem instalação. Não se atualiza sozinha. |

Requisito: Windows 10 ou superior, 64 bits.

## Instalação

1. Baixe o `CineStream-Setup.exe`.
2. Execute o arquivo e siga o assistente. Você pode escolher a pasta de instalação.
3. Ao terminar, o CineStream abre sozinho.

Se o Windows exibir o aviso "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital.

## O que o app oferece

- Catálogo de filmes e séries, com populares, destaque e navegação por gênero.
- Busca por título.
- Página de detalhes e player de vídeo.
- Conta de usuário com cadastro e login.
- Favoritos.
- Histórico do que você assistiu, com os itens mais recentes na tela inicial.
- Indicação de conteúdo dublado ou legendado.
- Watch Party: assista em grupo com o player sincronizado e chat.
- Links `cinestream://` que abrem o app direto em uma página.

## Atualizações

Com o instalador, o app verifica sozinho ao abrir se existe uma versão nova. Quando houver, aparece um aviso com as opções de baixar e de reiniciar para aplicar.

Se você usa a versão portátil, baixe o instalador mais recente desta página e instale por cima.

## Problemas e sugestões

Abra uma [issue](../../issues) descrevendo o que aconteceu e a versão do app.

## Privacidade

O app guarda sua conta, favoritos e histórico para funcionar. A política completa está na tela "Políticas de privacidade" dentro do app.
